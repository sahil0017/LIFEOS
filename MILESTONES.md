# LIFEOS milestones

These are outcome-based milestones, not delivery dates. The research tracks are
experiments; none guarantees a scientific breakthrough or free production hosting.

## M0: Project foundation

- [x] Add an Intelligence home and navigable previews of the main screens.
- [x] Add a typed engine registry and a local activity-summary plugin.
- [ ] Run the Expo app on a physical device or simulator.
- [ ] Create a learning goal and record a study session locally.
- [ ] Confirm data persists after restarting the app.
- [x] Type-check and test local data operations.

## M1: Personal memory and controls

- [ ] Add review, correction, and deletion of goals and events.
- [ ] Distinguish user statements, model inferences, and hypothetical scenarios.
- [ ] Design device security, export, backup, and recovery.
- [ ] Evaluate structured and keyword retrieval before adding embeddings.

## M2: Cloud and generative intelligence

- [ ] Deploy a TypeScript Cloudflare Worker on the free plan.
- [ ] Implement authentication and per-user authorization before cloud sync.
- [ ] Add optional D1 sync, conflict handling, and deletion propagation.
- [ ] Add consent-based Workers AI inference with quota and error handling.
- [ ] Monitor free-tier usage and document billing and privacy limitations.

## M3: Prediction, world models, and self-evaluation

- [ ] Define a measurable learning-goal outcome and prediction horizon.
- [ ] Implement and evaluate a simple forecast using time-ordered data.
- [ ] Record model versions, predictions, outcomes, and evaluation results.
- [ ] Compare a small Python state-transition model against the baseline.
- [ ] Present assumptions and uncertainty without claiming life-wide prediction.

## M4: Neuro-symbolic and multi-agent reasoning

- [ ] Validate generated plans against explicit user constraints.
- [ ] Compare a bounded planner/critic workflow with a single-model baseline.
- [ ] Require approval for memory changes and external actions.

## M5: Multimodal and causal research

- [ ] Evaluate one additional input modality with informed consent.
- [ ] Define a causal question and assumptions; report insufficient evidence.
- [ ] Benchmark extraction and causal experiments on suitable data.

## M6: Experimental intelligence laboratory

- [ ] Benchmark a small quantum experiment against a classical baseline.
- [ ] Compare a neuromorphic experiment with a conventional model.
- [ ] Compare evolutionary search with random search on the same task.
- [ ] Record datasets, evaluation splits, limitations, and compute costs.

## M7: Integration and release readiness

- [ ] Promote only evaluated models with a supported serving and rollback plan.
- [ ] Review privacy, security, accessibility, backup, and recovery.
- [ ] Verify free-tier limits, operating costs, and app distribution requirements.

Update a checkbox only after the outcome is verified. Research tracks can proceed
independently when their prerequisites and suitable data are available.
